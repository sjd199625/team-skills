> 执行方式：stable-chrome / Playwright / 混合
> 更新：<YYYY-MM-DD HH:mm>

## 覆盖矩阵

| servicer-ssr | SSR H5 页面 | 正向主流程 | REQ-001 | 待执行 |  |

## 用例质量

- 预期结果要可观测，不写“显示正常”。
- 列表数据先断言当前用例创建的标识存在，不断言绝对数量。
- 失败要保留截图、页面 URL 和关键请求。
- 阻塞要写原因、责任人和下一步，不把阻塞算通过。
- 联调用例要写清前端页面和接口响应之间的关系。
- 本次需求不涉及的入口写“不适用 + 原因”，不要留空。
- 核心项目或核心入口没有执行时，报告结论不能写“通过”。
