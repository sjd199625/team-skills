## 契约检查

- 前端是否重复 `.data` 解包；
- 字段名、大小写、枚举值是否一致；
- 分页参数名是否与真实接口一致；
- 空值、空数组、null 和缺字段是否区分；
- 日期/金额是不是字符串；
- 权限 header 是否被请求封装处理；
- 导出/下载是否走项目现有方式。
